# The Forbidden Folder — v1

A small, browser-based mystery / horror experience built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `the-forbidden-folder`).
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then save.

## Notes
- This is a fictional simulation. It does not read, modify, or upload real files.
- Version 1 includes a file explorer, document viewer, activity log, hidden folder reveal, and a first ending.
